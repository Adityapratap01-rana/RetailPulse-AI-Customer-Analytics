## 📌 Project Overview
RetailPulse is an AI-powered retail analytics project designed to analyze customer purchasing behavior, identify valuable customer segments, and forecast future sales.
The project uses Python, Machine Learning, and Deep Learning techniques to generate meaningful business insights from retail transaction data.

## 📂 Dataset
Dataset: UCI Online Retail II
The dataset contains retail transaction records, including:
- Invoice Number
- Stock Code
- Product Description
- Quantity
- Invoice Date
- Unit Price
- Customer ID
- Country
  
 ## 📊 Results & Insights
- Analyzed and cleaned retail transaction data.
- Identified 4,278 customers for RFM analysis.
- Created 5 customer segments.
- Applied K-Means and DBSCAN clustering.
- Developed sales forecasting models using Prophet and LSTM.
